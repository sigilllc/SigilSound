# Getting help

| You want to... | Go to |
| --- | --- |
| Ask how to do something, or share what you made | [Discussions](https://github.com/sigilllc/SigilSound/discussions) |
| Report a bug | [New issue, Bug report](https://github.com/sigilllc/SigilSound/issues/new/choose) |
| Suggest a feature | [Discussions, Ideas](https://github.com/sigilllc/SigilSound/discussions) first; an issue once it is agreed |
| Fix a typo or improve the docs | A pull request, see [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md). Never a public issue. |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before you ask, try the documentation and the browser REPL (both linked from the [README](README.md)): most questions about what a method does are answered by its example.

Sigil.Sound is looked after by one maintainer. We read everything, but we answer as time allows, usually within a week or two. This page covers the open-source library. Help for the Sigilgraph Audio Workbench app is separate and is found with the app.
