# Contributing

Sigil.Sound is open source under the MIT licence, and contributions are welcome: bug fixes, documentation, examples, tests and performance work. The files below are the single source of truth, kept in the repository so the site never drifts from them.

| What you need | Where |
| --- | --- |
| How to set up, what a good change looks like, how pull requests are reviewed | [CONTRIBUTING.md](https://github.com/sigilllc/SigilSound/blob/main/CONTRIBUTING.md) |
| How we behave | [Code of Conduct](https://github.com/sigilllc/SigilSound/blob/main/CODE_OF_CONDUCT.md) |
| Reporting a security problem, privately | [SECURITY.md](https://github.com/sigilllc/SigilSound/blob/main/SECURITY.md) |
| Asking for help | [SUPPORT.md](https://github.com/sigilllc/SigilSound/blob/main/SUPPORT.md) and [Discussions](https://github.com/sigilllc/SigilSound/discussions) |
| How the project is run | [MAINTAINING.md](https://github.com/sigilllc/SigilSound/blob/main/MAINTAINING.md) |

If you want to add documentation examples, start with [Writing doc examples](writing-examples.md): every audible member carries one, and a test plays each.
